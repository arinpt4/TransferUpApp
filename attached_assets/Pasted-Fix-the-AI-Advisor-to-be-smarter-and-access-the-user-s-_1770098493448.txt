Fix the AI Advisor to be smarter and access the user's profile data automatically.

PROBLEM:
- Advisor just repeats information the user can already see
- When asked "What courses do I still need?", it asks the user to list their completed courses
- Advisor should automatically access roadmap data and know what courses are complete/planned

FIX:

1. GIVE ADVISOR ACCESS TO USER'S ROADMAP DATA:
   When sending a message to the chatbot, include this context in the system prompt:
```javascript
   // Read user's roadmap data
   const roadmapData = await AsyncStorage.getItem('semesters'); // or 'quarters'
   const parsedRoadmap = JSON.parse(roadmapData);
   
   // Extract completed and in-progress courses
   const completedCourses = [];
   const inProgressCourses = [];
   const plannedCourses = [];
   
   parsedRoadmap.forEach(semester => {
     semester.courses.forEach(course => {
       if (course.status === 'Taken') {
         completedCourses.push({
           code: course.courseCode,
           title: course.title,
           units: course.units,
           grade: course.grade
         });
       } else if (course.status === 'In Progress') {
         inProgressCourses.push({
           code: course.courseCode,
           title: course.title,
           units: course.units
         });
       } else {
         plannedCourses.push({
           code: course.courseCode,
           title: course.title,
           units: course.units,
           semester: semester.name
         });
       }
     });
   });
```

3. MAKE ADVISOR PROACTIVE:
   Instead of just answering questions, the advisor should:
   - Analyze gaps in their course plan
   - Suggest courses they should take next semester
   - Warn about missing prerequisites
   - Remind about important requirements they haven't started
   - Calculate how many more units/courses needed
