Build a mobile-first Transfer Pathway Optimizer app for the Replit Mobile Buildathon. This must be a native-feeling mobile application that uses the ASSIST.org API for California community college transfer data.
Mobile App Requirements:

Mobile-Native Interface:

Design for iOS/Android mobile screens (responsive, touch-friendly)
Bottom navigation bar for main sections
Swipeable course cards
Pull-to-refresh for updating data
Native-feeling animations and transitions
Mobile-optimized forms with proper input types


App Structure (Tab Navigation):

Home Tab: Quick overview, progress toward transfer
Schools Tab: Select and compare target universities
Roadmap Tab: Semester-by-semester course plan
Alerts Tab: Warnings, deadlines, course conflicts
Profile Tab: Settings, saved data, GPA calculator


ASSIST.org API Integration:

API base URL: https://api.assist.org
Key endpoints:

GET /api/institutions - fetch all CCs and UCs/CSUs
GET /api/agreements - get articulation agreements
GET /api/articulation - get course equivalencies


Implement proper error handling and offline support
Cache responses for better mobile performance

Onboarding flow (first-time user setup)

Progress bars showing completion %
